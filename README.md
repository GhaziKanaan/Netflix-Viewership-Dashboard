# Netflix Viewership Dashboard

## Project Overview
This project analyzes Netflix content performance and audience engagement using interactive Tableau dashboards and business intelligence techniques.

The goal of this project is to identify:
- High-performing genres
- Audience engagement trends
- Content popularity patterns
- Relationships between ratings, votes, and viewership

---

## Tools Used
- Tableau
- Excel
- Python
- SQL

---

## Key KPIs
- Total Viewership
- Total Content Titles
- Average Audience Rating
- Audience Engagement Metrics

---

## Dashboard Features
- Genre Performance Analysis
- Viewership Trends Over Time
- Popularity vs Viewership Analysis
- Audience Engagement Dashboard
- Interactive Filters and Visualizations

---

## Business Insights
- Certain genres consistently drive higher engagement
- Audience ratings and votes influence viewership trends
- Seasonal content release timing impacts performance
- Interactive dashboards improve executive decision-making
